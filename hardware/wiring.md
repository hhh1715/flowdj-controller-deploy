# 硬體接線參考

> **此文件為除錯參考，正常使用不需要關心**。硬體已組裝完成、USB 接上即可運作。

## 整體架構

```
[電腦] ←—USB—→ [Teensy 4.0] ←—I²C 共用 SDA/SCL—→ [MPR121 #1]
                                                   [MPR121 #2]
                                                   [MPR121 #3]
                              ↓
                         每顆 MPR121 接 12 個導電墨電極（共 36 通道）
```

## Teensy 4.0 接腳使用

| Teensy Pin | 用途 | 接到 |
|---|---|---|
| 18 (SDA0) | I²C 資料線 | 三顆 MPR121 共用 |
| 19 (SCL0) | I²C 時脈線 | 三顆 MPR121 共用 |
| 3.3V | 電源輸出 | MPR121 VIN（每顆都要 100nF 去耦電容到 GND） |
| GND | 共地 | 全部 |

**注意**：MPR121 是 3.3V 邏輯，**不能接 5V**。

## MPR121 I²C 位址設定

每顆 MPR121 的 ADDR 接腳決定它的 I²C 位址：

| ADDR 接到 | 位址 | 本專案使用 |
|---|---|---|
| GND | 0x5A | #1（按鈕 + Jog） |
| 3.3V | 0x5B | #2（速度 slider） |
| SDA | 0x5C | #3（PAD + 音量 fader） |
| SCL | 0x5D | （未用） |

## 通道對應

### MPR121 #1（0x5A）
| ELE | 元件 | 備註 |
|---|---|---|
| 0 | CUE 鈕 | |
| 1 | Play 鈕 | |
| 2 | SYNC 鈕 | |
| 3 | 保留 | |
| 4–11 | Jog 8 個感應扇區 | 角度 0°, 45°, 90°, ..., 315°（**逆時針**遞增） |

### MPR121 #2（0x5B）
| ELE | 元件 | 備註 |
|---|---|---|
| 0–9 | 速度 slider 10 段 | 0=最頂端（慢，-8%），9=最底端（快，+8%） |
| 10–11 | 未用 | |

### MPR121 #3（0x5C）
| ELE | 元件 | 備註 |
|---|---|---|
| 0 | PAD 1 | |
| 1 | PAD 2 | |
| 2 | PAD 3 | |
| 3 | PAD 4 | |
| 4–8 | 音量 fader 5 段 | 4=最小，8=最大 |
| 9–11 | 未用 | |

## 硬體故障排除

| 症狀 | 可能原因 |
|---|---|
| 燒韌體後 Serial Monitor 印 `MPR121 #1 not found` | I²C 線斷了、或位址 ADDR 接錯 |
| 某顆 PAD / 一段 fader 完全沒反應 | 該電極與 MPR121 之間斷線 |
| 觸碰時 jog 角度跳到固定值 | 某顆 jog 電極短路或鬆脫，centroid 計算被拉偏 |
| 完全沒 USB MIDI 訊號 | Arduino IDE 燒錄時 USB Type 沒選 `Serial + MIDI` |
